## 🏆 Featured Project

### ClashLens

**ClashLens** is a modern analytics platform for **Clash of Clans** built with **Next.js** and the **official Clash of Clans API**.

#### Highlights

* 📊 Live clan analytics
* 👥 Member insights
* 🏰 Town Hall & League distribution
* 📈 Performance overview
* ⚡ Fast, responsive dashboard
* 🎨 Clean, modern UI

#### Tech Stack

Next.js • React • TypeScript • Tailwind CSS • Node.js • PostgreSQL • Clash of Clans API

🌐 **Live:** https://clashlens.app
